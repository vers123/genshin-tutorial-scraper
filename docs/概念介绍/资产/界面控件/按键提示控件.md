# 一、按键提示的功能

![](../../../images/dd06d08d393af9ca.png)

*按键提示*是一种封装的提示信息控件，可配置PC、键鼠和手柄端的快捷键

按键提示控件是客户端控件，可以挂载*客户端脚本*，支持通过*客户端脚本*进行调用

查询接口：可通过`UIKeyHintControl`在API文档里查询关联脚本接口

# **二、按键提示的配置**

![](../../../images/a470c87aef8c0373.png)

## 1.按键提示设置

可用于配置PC、键鼠和手柄端的快捷键显示

## 2.手柄导航
