# 一、文本视窗的功能

![](../../../images/605970998993303c.png)

文本视窗的基本功能和文本框一致，详见[文本框界面控件](/ys/ugc/tutorial//detail/mhnltrr3g966)

文本视窗在文本框的基础上额外支持了滚动功能

文本视窗控件是客户端控件，可以挂载*客户端脚本*，支持通过*客户端脚本*进行调用

查询接口：可通过`TextWindowControl`在API文档里查询关联脚本接口

# **二、文本视窗的配置**

![](../../../images/020eee947fdc8d51.png)

## 1.文本框设置

*是否可滚动：*开启时，文本框支持滚动显示*显示滚动条：*需是否可滚动选项开启时才能编辑；开启时，文本框支持滚动显示

![](../../../images/8697dd0adfb28b24.png)

## 2.手柄导航

*可被手柄摇杆导航选中：*控制手柄导航是否可选中此控件

开启后可编辑手柄四向移动时选中的其他控件

![](../../../images/73fdbda442b7cf8f.png)
