# 一、计时器的功能

![](../../../images/6ae05cc5c682476f.png)

用于显示时间进度的界面，包括倒计时、正计时两种表现方式。

# **二、计时器的编辑**

![](../../../images/6be0cd3d732d6ee7.png)

|  |  |
| --- | --- |
| 配置参数 | 说明 |
| *类型* | 正计时、倒计时 |
| *指定计时器* | 会枚举符合“类型”的所有预定义全局计时器 |
| *来源实体* | 默认配置为关卡实体，可选择关卡实体，或者玩家实体 |
