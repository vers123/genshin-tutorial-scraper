# 一、交互按钮的功能

![](../../../images/f8cf21d9c1acaf62.png)

关卡运行中，点击和外接设备输入，都可以触发该界面控件的交互。

支持玩家进行交互，在选择类型为“交互事件”时，交互后会向节点图发送*界面控件组触发时*事件

# **二、交互按钮的编辑**

![](../../../images/724bb7d327e8deba.png)

*按键映射-键鼠*

提供PC按键供选择，作为输入交互项。选择后会显示在编辑窗口按键下方

![](../../../images/a991b95c93db8bf3.png)

*按键映射-手柄*

提供手柄按键供选择，作为输入交互项。选择后会显示在编辑窗口按键下方

![](../../../images/339dd90500200b38.png)

*大小*

可以修改交互按钮的大小，大的为64\*64，小的为40.96\*40.96

![](../../../images/5cd5242189231eef.png)

*类型*

![](../../../images/506f65e72910ffa5.png)

按钮技能 

需指定一个技能，对应的图标和功能编辑详情可见角色技能编辑。[技能](/ys/ugc/tutorial//detail/mho81frl33im)

![](../../../images/fa2761b0e44a9c45.png)

交互事件

![](../../../images/74e34581deb3f64a.png)

代表触发后会向节点图发送事件

*按钮图标*

通过操作![](../../../images/27e526c194f0b1a8.png)可以配置按钮的显示图形，并同步显示在编辑窗口。

![](../../../images/dfed3410c8e99ff9.png)

*按钮冷却时间*

每次使用技能后，需要间隔该配置时间才能再次使用。并且在此期间，该按键图形会置灰

*按钮次数限制*

若开启，则激活显示使用次数的配置及功能

![](../../../images/b8f0b9fbc2e26d0e.png)

![](../../../images/78ee5b57a95d71ff.png)

*无次数时隐藏*

若开启，则当配置的玩家自定义变量数值为0时，按键隐藏

*次数*

次数限制开启才开放配置。根据不同的玩家，可以配置不同的使用次数，该次数只能读取对应玩家的自定义变量。配置后的默认次数显示在编辑窗口内的按键上。若需要次数变化，需要在节点图中编辑玩家的自定义变量使用情况。当配置的自定义变量变化时，按钮次数显示会同步变化。使用道具

![](../../../images/65215319062b129f.png)

*选择变量*

![](../../../images/5b1ac54bb64ffc87.png)

可以选择玩家自身实体的变量

*无道具时表现*

![](../../../images/577eafe5f70d4e4d.png)

分为图标置灰、不显示图标、隐藏按钮三种情况

# 三、通过节点图管理交互按钮

**界面控件组触发时**

在关卡运行中，通过按钮界面控件制作的界面控件组，被执行交互操作会发送节点图事件”界面控件组触发时“，此事件只有触发交互的*玩家*节点图可以获取

![](../../../images/1ff2fa5d1e015a14.png)
