# 一、客户端控件容器的功能

![](../../../images/7d6189109d2acb82.png)

*客户端控件容器*用于使*客户端控件*能在奇域关卡运行时正常显示

界面布局中不存在客户端控件容器时，所有客户端控件和挂载在控件上的脚本将无法正常运行和显示

# 二、客户端控件容器的编辑

## 1.添加客户端控件容器

在*界面控件组编辑窗口*，添加界面控件模板-客户端控件容器

![](../../../images/3a0db24fb603cdb4.png)

## 2.界面配置-画布设置

通过选中上述添加的客户端控件容器-画布设置-前往编辑，打开客户端控件容器详情，以编辑其中的客户端控件

![](../../../images/da52e59bd1262ef5.png)

## 3.界面配置-客户端控件容器/详情

通过上述打开的客户端控件容器详情界面，点击添加控件，可以添加所需的客户端控件

![](../../../images/1e8554074320858b.png)
