# 一、模板引用控件的功能

![](../../../images/645950a70de718ee.png)

*模板引用控件*可以引用其他客户端控件模板，并提供预览

模板引用控件是客户端控件，可以挂载*客户端脚本*，支持通过*客户端脚本*进行调用

查询接口：可通过`ReferenceControl`在API文档里查询关联脚本接口

# 二、模板引用控件的配置

![](../../../images/bdee4cc1b40f0df8.png)

## 1.模板引用

*引用控件模板：*可以引用已存为客户端模板的控件，运行时模板引用控件的功能和表现与被引用模板一致

## 2.手柄导航

*可被手柄摇杆导航选中：*控制手柄导航是否可选中此控件

开启后可编辑手柄四向移动时选中的其他控件
