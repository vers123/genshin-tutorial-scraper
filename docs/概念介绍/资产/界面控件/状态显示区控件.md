# 一、状态显示区的功能

*状态显示区*可以配置在界面布局中，监听实体上的单位状态，并按照自定义样式进行展示

状态显示区控件仅供信息展示使用，不可交互

与消息队列不同，状态项在加入队列，移出队列时，不会额外附带动画表现

# **二、状态显示区的编辑**

![](../../../images/fb7b4c00d4664584.png)

## **1.添加状态显示区**

在*界面控件组编辑窗口*，添加界面控件模板-状态显示区

![](../../../images/db625d83f6d62dfc.png)

## 2.状态项样式设置

与页签控件，单选项视窗控件类似，在样式设置中，可以定制状态项的样式

![](../../../images/295a11eb409f45a7.png)

奇匠可以点击【详情编辑】在状态项素材组中加入任意素材。比如可以添加界面动效，使得每次新状态项加入显示区时，触发界面动效的播放，以提示新状态的更新

![](../../../images/55f7ff58823444a9.png)

## 3.状态显示区功能设置

![](../../../images/7bbed04e06cf742e.png)

初始填充点：

第一个状态项加入队列时的初始填充位置

![](../../../images/625b355948b3ce44.png)

填充方向：

状态项的填充方向

![](../../../images/5f8f80bae6292e98.png)

新状态插入位置：

可以搭配【填充方向】【初始填充点】参数实现不同的效果

![](../../../images/e6ecd16ba55438da.png)

举例：当排列限制=自动换行时：

若初始填充点=左上，填充方向=纵向，新状态插入位置=队列结尾，则状态在加入队列时，会从上到下进行填充

若初始填充点=左下，填充方向=纵向，新状态插入位置=队列开头，则状态在加入队列时，会从下到上进行填充

对齐：

![](../../../images/9278a4b96cc115b3.png)

与文本框对齐类似，可以设置所有状态项关于父级控件的上下左右对齐方式

## 4.注意事项

与消息队列控件不同，状态显示区的【排列限制】参数会受到状态项填充方向的影响

![](../../../images/d22d540e79809e6b.png)![](../../../images/6487b1f84fa55066.png)

排列限制=固定行数时，状态项会优先填充满当前列，再换列填充；

排列限制=固定列数时，状态项会优先填充满当前行，再换行填充；

# **三、状态显示区的状态项显示步骤**

以下三条需要同时满足才可以显示该状态

## 1.确定监听实体对象

在功能页签中的状态项配置中，先指定监听的实体对象

![](../../../images/eec7e4277c19e3a8.png)

## 2.关联单位状态

点击详情编辑打开界面，点击【关联单位状态】选择需要显示的单位状态

![](../../../images/77297a777d6f3db9.png)

## 3.单位状态中添加控件推送

对需要显示在控件内的单位状态，配置时要添加“状态显示区添加状态”的效果，并选择需要推送的目标控件

![](../../../images/16404c08aa63a42b.png)

# **四、额外说明**

经典模式也可以配置特殊数字控件了

状态显示区控件新增施加来源不同时堆叠显示开关，关闭堆叠显示后，在不同槽位的同类型的单位状态会区分显示，需要与特殊数字控件的监听父级模式配合使用

![](../../../images/eb72745515a15ef2.png)
