# 一、环境配置的定义

环境配置包含一系列环境表现相关参数，可用于丰富场景中各要素的表现

环境配置需要预先定义，并应用于各玩家的客户端

# 二、环境配置的编辑

切换至地形编辑页签，可在左侧选择环境配置。

![](../../images/71ceac73dcb43a00.png)

点击【新建环境】并【确认创建】即可新建一份环境配置

![](../../images/57e9da743b5103a1.png)

## 1.环境配置

### (1)生效目标

![](../../images/48d3a94595311486.png)

可以选择该份环境配置对哪些玩家生效

### (2)背景预设

![](../../images/8cf2a4d9f1726fc0.png)

可选择一份背景预设，决定场景表现的大致风格

*随时间自动切换*：如果启用，则场景中背景相关的要素都会随时间变换。如果不启用，则不会随着时间变换，而是保持当前配置的固定值

*设定时间点*：表示当前的背景设置保存在哪个时间点，不同的时间点可以保存不同的背景设置，并在可动态变化时随着环境时间的变化而变化

*动态预览*：启用【随时间自动切换】时，可以打开动态预览

![](../../images/57383516ac9c6073.png)

*参考时间点列表*：可以选择任意时间点查看其对应的背景设置

*天气配置*：可以选择一份提前配置好的天气配置与当前时间点关联

*每秒流逝时间(分钟)*：开启预览时，现实时间每经过一秒游戏内时间会经过多久。24为提瓦特时间，可配置区间为[0,60]

*当前预览时间*：表示当前正在预览的时间点

*预览*：点击【预览】则环境时间会按照设置的【每秒流逝时间】进行流逝，以此来动态查看24小时内的环境变化

### (3)背景设置

![](../../images/61354e1c4ab25a08.png)

*背景旋转*：调整背景的角度

*直射角*：环境主光源的直射角度

*强度*：环境主光源的强度，数值越高越亮

*模糊程度*：环境主光源的模糊度，数值越高越模糊

*受光颜色*：环境的受光颜色

*滤镜风格*：在相机层增加滤镜效果

*光晕颜色*：设置环境的光晕颜色

*光晕强度*：设置环境的光晕强度，数值越高光晕越明显

*天际线强度*：设置天空的天际线强度，数值越高天际线越明显

*天空背景色*：可以调整天空的背景色，分为上下层向阳天空背景色、上下层背阳天空背景色

*环境颜色*：可以调整环境的颜色，分为顶面颜色、侧面颜色、地面颜色

![](../../images/28d8d99a49281c0a.png)

支持配置颜色配置项可以通过选色器来调整颜色和透明度

![](../../images/5f2995e17d5e5847.png)

![](../../images/080fded56d6bd270.png)

启用【随时间自动切换】时，可以查看该参数在对应时间点的配置值

### (4)环境要素

![](../../images/728aefc1dc531b54.png)

*太阳*：默认开启，可以调整颜色、亮度、角度、运动轨迹倾斜角度和大小

*月亮*：默认开启，可以调整颜色、亮度、角度、运动轨迹倾斜角度、大小和圆缺

*星星*：启用后可设置密度、强度

*银河*：启用后可设置强度、受光颜色

*云*：启用后可设置云的类型高云、中云、低云、薄云以及对应的强度和受光颜色

## 2.光源配置

![](../../images/68c9b31d34ba82f9.png)

与这份环境配置绑定的光源，当环境配置生效时，对应的光源列表也会一起生效。

### (1)光源配置的入口

![](../../images/8b57e6e3a1acc7fa.png)

点击添加光源>打开光源管理工具，可以打开光源管理工具

![](../../images/b6144e0b95ec1bda.png)

点击左上角系统菜单，点击【光源管理】可以打开光源管理工具

### (2)光源配置

![](../../images/8d75e6742f1dfd38.png)

光源的参数设置：

*归属文件*：指被哪些环境配置引用

*位置、旋转*：控制其在场景中的位置、旋转。

*光源类型*：目前可选点光源、聚光灯两种。

*颜色*：照射在其他模型上时，模型显现的颜色变化

*半径*：照射的半径

*强度*：被照射的模型上，颜色或亮度变化的程度

*生效范围*：角色进入该范围时，光源才会被加载，可用于性能优化。

![](../../images/553a00da2cd513df.png)

## 3.天气

![](../../images/30367187037a47ee.png)

一份环境配置下可设置多份天气配置，可随环境配置一同启用

![](../../images/b39a954dbcf21392.png)

*初始生效*：该份配置是否初始生效

*天气类型*：当前仅支持配置雾

*随时间自动切换*：如果启用，则该天气会随时间变换。如果不启用，则不会随着时间变换，而是保持当前配置的固定值

*距离雾设置*：根据镜头位置，使远处的模型、天空显现被雾遮挡的效果。

*高度雾设置*：根据场景高度，使远处的模型、天空显现被雾遮挡的效果。

# 三、环境时间

关卡设置中可定义游戏开始时的时间点，以及游戏中的时间流逝速度，也可以通过节点调整。

环境时间是全局唯一的运行值，无论各玩家应用的环境配置如何，服务器中将会持续地推进环境时间。仅有勾选“*随时间自动切换*”的环境配置生效时，才会看到环境时间变换产生的效果变化

注意：关卡设置中的流逝时间配置为关卡运行中实际的流逝速度，而环境配置中的流逝时间配置为预览时的流逝速度，与关卡运行时无关
