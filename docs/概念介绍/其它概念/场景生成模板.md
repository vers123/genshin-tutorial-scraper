# 一、功能简介

场景生成模板是一种可以让创作者(奇匠)通过简易操作生成大面积场景的工具，支持创作者(奇匠)自定义生成物的种类与数量，灵活创建不同的场景。

# 二、预设模板的使用

为了方便创作者(奇匠)直接使用，我们提供了部分预设模板。

## 1.入口

进入“实体摆放”界面，“场景生成模板”-“预设模板”页签，选择具体的模板并确认导入。

![](../../images/db524ac7ff47fda1.png)

## 2.生成实例

在“未分类页签”或自己创建的页签中点击（或者拖动）模板，会在场景创建对应模板的实例。

![](../../images/f28ca22ff9b15d2c.png)

## 3.调整实例参数

选中刚刚创建的实例，在“基础属性”页签可以调整实例的生成规则、生成范围等参数。

![](../../images/b334693dc696988e.png)

进入”资产配置“页签可以调整生成物的详细参数（例如资产种类、密度等）。具体参数含义可以参考本文档的第四部分“参数介绍”。

![](../../images/478c28feab7f0319.png)

## 4.生成场景

调整好参数后，点击“随机预览”可以预览生成效果，对结果满意后点击“确认生成”可以将生成物创建在关卡场景中。

![](../../images/52b55d869de68ff7.png)

## 5.调整生成物

将生成物创建在场景中后，如果想要一起移动或删除生成物，可以点击场景实体组右上角按钮选择“全选”或“删除”。

![](../../images/5c8dde7d1637b590.png)

# 三、场景生成模板的创建

若需要自定义生成模板可以参考以下步骤：

## 1.功能入口

进入“实体摆放”界面，“场景生成模板”页签，点击“管理模板”按钮。

![](../../images/1c85aff2c0904963.png)

或者打开系统菜单，点击“场景生成模板管理”。

![](../../images/7fbce1c7fa718422.png)

## 2.创建模板

点击“新建场景生成模板”。

![](../../images/08806de681209b67.png)

## 3.配置参数

点击“资产配置”，配置具体参数。

![](../../images/4c72e1db52ba87b7.png)

## 4.完成

配置完成并保存以后，可以在资产栏“场景生成模板”页签看到刚刚新建的模板。

![](../../images/166cd2631a378dac.png)

# 四、参数介绍

## 1.基础属性面板

“基础属性”面板主要包含两部分——生成规则、生成范围。

![](../../images/ea934c1bd530dbe4.png)

### (1)生成规则

**散布规则预设列表：**可以点击下方“随机预览”按钮以预览随机效果。对散布满意的话可以点击“保存散布规则”。下次可以在“散布规则预设列表”里选用保存过的规则生成。

![](../../images/4a38d8d7a765949c.png)

**锁定生成结果：**开启后每次生成时都会复制和上次一模一样的结果。

### (2)生成范围

**生成区形状：**影响生成区的形状。目前提供两种形状——长方体和圆柱体。

![](../../images/9b7d2215093338c2.png)

## 2.资产配置面板

在“资产配置”面板中，创作者(奇匠)可以修改每个生成层的具体参数。

默认有五层，分别是岩石层、建筑层、树木层、植被层和装饰物层。也可以自己新建自定义层。

![](../../images/cc4e4980132cb274.png)

### (1)层参数

**生成密度：**控制同一层中生成物的生成密度。数字越小，生成物越稀疏；数字越大，生成物越稠密。

![](../../images/96a9f75f16c8d127.png)![](../../images/550318a2db8fe925.png)

**生成随机性：**控制生成物的采样点的震动幅度。0趋近均匀分布，1则趋近杂乱分布。

![](../../images/1951f847bc95e1f3.png)![](../../images/82e7ebb13dd6065e.png)

**是否基于地形生成：**只有岩石层拥有。控制岩石层是否基于场景地形生成。

![](../../images/99066db48c67bf74.png)![](../../images/559e3e3279db8532.png)

**伴生范围：**植被层专属参数，定义植被层生成物以树木层内物件为圆心的有效生成半径。超过伴生范围则不会生成。

若树木层物件的**生成间隔距离**取值过大，或植被层**伴生范围**取值过小，均可能导致植被层无生成物显示。建议通过两种方式优化：a.调小树木层物件的**生成间隔距离**（可设置为负数）；b.增大植被层的**伴生范围**的数值

![](../../images/c512e7d0916531f7.png)![](../../images/dc794e4e0215a538.png)

### (2)层的详细编辑

如果想要详细编辑层中的资产类型、权重、生成间隔距离和变换区间，那么可以在对应层中点击“详情编辑”。

![](../../images/7998300da859c279.png)![](../../images/74aefa25c9c80f61.png)

**权重：**影响同一层中不同模型的生成权重。

![](../../images/6572b333faabc428.png)![](../../images/7a210b08770a2a67.png)

**生成间隔距离**：控制下一层生成物与当前模型的间隔偏移量，支持配置正负数值。

以当前物件圆心为原点画一个圈，圈的半径为当前物件外包围盒半径 + 该值，此圈形成的区域内，禁止生成下一层物件

![](../../images/4dedf5bb6ca4cc3d.png)![](../../images/f2f9728157257c5a.png)

**模型资产：**点击“添加资产”可以添加更多资产。可以在“模型资产库”中选择自己需要的资产类型。

![](../../images/030fff66d8861190.png)

**变换区间：**控制资产的位置、旋转和缩放的抖动范围。

![](../../images/af11aa8fd5fd7716.png)

# **五、特殊说明**

1.层是依次生成的，首先生成岩石层，然后依次是建筑层、树木层、植被层......除了岩石层之外，所有的层都遵循“剔除规则”——剔除上一层的生成物之后在空处生成下一层的生成物。（如果上一层过密，可能导致后面的层没有地方生成。）2.植被层是特殊层，遵循“伴生规则”——植被层会伴生树木层。如果树木层不生成，则植被层也不会生成。
