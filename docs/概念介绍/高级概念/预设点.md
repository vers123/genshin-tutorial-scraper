# 一、预设点是什么

预设点是一组场景中的世界位置和朝向的数据信息。

预设点可以被需要点位信息的功能所引用，例如出生点、复苏点、节点图获取点位等。

![](../../images/320f35f11ddbc77a.png)

通过点击“创建预设点”，在当前编辑窗口中央生成新的预设点。并自动开启命名编辑。

### **(4)预设点的参数**

![](../../images/24061f9d0fffc012.png)

*预设点名称*预设点的名称，可以修改

*预设点索引* 作为节点的入参，是预设点的唯一标识

![](../../images/9c1bcf5d951445ea.png)

|  |  |
| --- | --- |
| 配置参数 | 说明 |
| *锁定变换* | 勾选后不可调整预设点的位置和旋转 |
| *是否在场景中显示* | 取消勾选后，只留坐标轴，定点模型不可见 |
| *位置* | 预设点的位置数据 |
| *旋转* | 预设点的朝向数据 |
| *单位标签* | 可以给预设点添加单位标签。详见[单位标签](/ys/ugc/tutorial//detail/mhzldmiwdgu4) |

# 三、预设点的引用

## 1.出生点

在“关卡设置”-出生点配置中，可通过*选择点位*引用预设点，作为出生点

![](../../images/3c3f963c0f161110.png)

## 2.复苏点

在“关卡设置”-复苏点配置中，可通过*选择点位*引用预设点，作为复苏点

![](../../images/3a4eeebdf9245a39.png)

## 3.节点图
