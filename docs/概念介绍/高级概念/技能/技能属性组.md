# 一、什么是技能属性组

*技能属性组*可以被技能关联，并通过修改属性组的值来动态修改技能的部分行为

# 二、技能属性组的编辑

在系统菜单中点击【技能资源管理】，打开技能资源管理界面

![](../../../images/6ea24baf1037aa22.png)

在打开的界面中选择【技能属性组】页签即可编辑全局可用的属性组配置

![](../../../images/9bb210b1b9cce3f4.png)

*属性组命名*：一个属性组配置的名称

*配置ID*：技能属性组的唯一标识，在外部系统调用时依赖该ID

*属性类型*：技能属性组支持配置不同的属性类型，当前版本仅支持两种属性类型

*动画速度倍率*：可以在基础动画播放速度的基础上叠加额外的变化值，让动画播放的速度更快或更慢，对应的技能节点图触发时机也会受此影响

*冷却时间倍率*：可以在技能的基础冷却时间上叠加额外的变化值，让技能冷却速度更快或更慢

# 三、属性类型的计算公式

技能额外属性的叠加规则遵循以下公式：

**最终动画速度=技能属性组初始值+Σ(单位状态修改值\*层数)+Σ技能轨道修改值**

*技能属性组初始值*：在技能配置上的初始值

*单位状态修改值*：通过单位状态额外添加的修改值

*层数*：单位状态的总层数

*技能轨道修改值*：通过技能轨道修改的值

**最终技能冷却=原始技能冷却\*（技能属性组初始值+Σ(单位状态修改值\*层数))**

*原始技能冷却*：在技能配置上的初始值

*技能属性组初始值*：在技能配置上的初始值

*单位状态修改值*：通过单位状态额外添加的修改值

*层数*：单位状态的总层数

# 四、技能属性组的修改方式

## 1.技能配置引用

在技能编辑界面，可以通过数值配置内的“技能属性组”字段，点击【编辑】打开属性组编辑界面

通过下拉框选中预先配置的技能属性组，将技能和预先配置的属性组进行关联，属性组的初始值即为全局定义的默认值

![](../../../images/8ce78ce049eff011.png)

## 2.单位状态修改

通过单位状态【调整施法速度】和【调整冷却缩减】，奇匠可以在游戏运行时动态的修改某个技能属性组的数值

![](../../../images/26a67eef5b96ec4e.png)

## 3.技能轨道修改

通过技能动画编辑中的【状态轨道】添加“调整动画速度”事件，可以在技能释放的过程中对部分动画阶段实现动画速度修改。通过该方式修改只支持固定参数，通常用于优化动画的表现

![](../../../images/2704d85051bf8c25.png)
