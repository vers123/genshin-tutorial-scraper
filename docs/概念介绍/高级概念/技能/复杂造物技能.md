# 一、造物技能的定义

*造物技能*是让造物执行某一段预设行为的封装。在提瓦特大陆中，丘丘人的丢史莱姆，丢石头等，都是一个技能。

技能主要实现三个基本功能：

*造物动画*的调用：在技能编辑时，奇匠可以定义技能释放后的造物动画演出效果触发客户端节点图：通过编辑技能动画*节点图事件轨道*上的事件，可以在动画的特定阶段触发指定的客户端节点图配置*技能状态*：在动画播放的过程中，可以指定特定的时间窗口附加持续性的逻辑，比如播放特效、设置造物朝向等

# 二、造物技能的编辑

## 1.编辑入口

造物技能编辑的入口位于战斗预设页签的技能页签下

![](../../../images/731948af61a12889.png)

点击![](../../../images/8d63dfa66bf3abf0.png)，在弹窗选择要为哪个造物创建技能，这决定了编辑技能时，提供的技能动画

最后点击【确认创建】即可完成新技能的添加

![](../../../images/1f74027eb45b72ca.png)

## 2.技能参数

一个技能的参数配置如下图：

![](../../../images/66ae3fc2277d4be8.png)

*配置ID*：技能的唯一标识，在节点图修改对应的技能配置时，引用该ID

*技能类型*：目前分为两种

*瞬发技能*：无法编辑动画，在接受输入的瞬间立即触发逻辑

*普通技能*：基础的技能类型

### (1)基础设置

![](../../../images/dd72e77431a25f90.png)

*归属模型*：不同造物模型可用技能动作不同，切换模型时会清空当前造物技能所有配置

*技能备注*：奇匠可自定义为该技能做一些备注

### (2)通用配置

![](../../../images/c4a81af7fb79241c.png)

|  |  |
| --- | --- |
| 配置参数 | 说明 |
| *可打断其他技能* | 开启后可以在其他技能正在释放时，打断其他技能释放该技能 |
| *自动面向目标* | 开启后技能自动面对目标释放 |
| *击败目标是否继续释放* | 关闭后如果目标不存在则不使用 |
| *目标可达时释放技能* | 开启时若目标所在位置可正常寻路抵达，会释放技能 |
| *目标不可达时释放技能* | 开启时若目标所在位置不可正常寻路抵达，会释放技能 |

# 三、造物技能的动画编辑

![](../../../images/b2c603a384bebaea.png)

在定义完了技能的通用配置后，即可点击动画编辑，来继续编辑技能释放后的具体逻辑，仅普通技能类型支持配置动画

![](../../../images/e178016401bad79f.png)

界面如上图，以时间轴的形式来进行配置，分为动作轴和逻辑轴。在技能释放时，从前往后按时间依次触发动作轴上的动画，以及逻辑轴上的事件，依次来实现整个技能的具体效果。

### 1.添加动作

首先我们需要添加对应的*动作*，入口在上图“1”所示位置，点击可选择目前可用的*造物动画*

![](../../../images/68cdc85738e392d2.png)

动画是整个*技能轨道*的尺度，事件轴的总长度等于所有动画的时长之和，在对应的动画时点添加事件，即可让表现和逻辑匹配

### 2.编辑事件轨道

事件轨道在上图"2"所示位置

*事件轨道*分为四种类型：

*开始事件轨道*：在技能开始释放时立即触发的时点

*结束事件轨道*：在技能的动作全部播放完成后触发的时点

*节点图事件轨道*：可以根据动作进度进行打点并添加事件的轨道，在该轨道下可选择具体的动画进度位置，并添加一个*本地节点图*，如下图。当动画进行到配置的进度处时，本地节点图会被触发

![](../../../images/c9eeb9b34079b5f1.png)

*状态轨道*：用于定义非触发类型的表现，如持续播放特效等，如下图，并且可以自由配置该状态的开始时点和结束时点

![](../../../images/a9531bd1831870e9.png)

注意：状态轨道中的【设置造物朝向】事件，在多个事件有重叠的时候，互相之间逻辑上会有竞争关系，所以有重叠的事件不会被执行。如下图中第二个事件不会被执行，只会执行第一和第三个【设置造物朝向】事件

![](../../../images/48610d86967ed50b.png)

### 3.瞬发技能

![](../../../images/e2e0a86e8a3a9e74.png)

界面如上图，由于瞬发技能的所有逻辑都在技能释放瞬间触发，且也不会调用动画。因此瞬发技能不可添加动作，且只保留开始事件轨道

# 四、造物技能的添加

在复杂造物的特化配置，造物技能管理中，点击详情编辑进入详情界面

在引用技能中点击"+"，并在左下角弹出的页签中选择预先定义好的技能即可完成添加

![](../../../images/dfea19b948c63cfd.png)
