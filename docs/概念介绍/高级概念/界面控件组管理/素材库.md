# 一、素材库的定义

*素材库*中奇匠可以创建多个自定义素材组

素材组是对单个/多个界面控件模板，进行组合、编辑参数后保存的数据

在支持配置素材组的界面控件中，可以引用已经定义好的素材组来丰富控件表现

# 二、素材库的编辑

## 1.创建素材组

选择素材库，点击【添加素材模板】可以将目前支持的界面控件模板添加到素材详情中

![](../../../images/a1f88e61c8af6f09.png)

添加完成后，可以选择任意界面控件进行组合，点击【创建素材组】可以生成一个素材组![](../../../images/a09230fc48c1cda6.png)

创建完成素材组以后可以选择是否开启遮罩，开启遮罩可以对该素材组配置遮罩

注意：遮罩不支持遮罩特效

![](../../../images/d9b9af56bb0d2b20.png)

## 2.素材组的引用

以状态显示区控件为例，在引用素材区可以引用素材组

![](../../../images/c4d594b3e1c46303.png)

点击详情编辑，可以新创建素材组，也可以直接引用已经创建好的素材组

![](../../../images/a13f124083a3e2aa.png)

## 3.素材组编辑时预览设置

进入素材组编辑界面后，当前编辑的素材组将以蒙版与控件所处的画布隔离，素材组在画布中的位置仅供编辑时预览，不会影响素材组基于所属控件的相对位置

在设置中可设置蒙版和素材组来源控件在编辑时预览的可见性

![](../../../images/ef9e8f331727d303.png)
