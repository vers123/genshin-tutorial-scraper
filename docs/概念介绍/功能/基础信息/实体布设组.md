# 一、实体布设组的功能

*实体布设组*可用于批量管理布设实体，并可以通过相关节点实现实体的批量创建和销毁。

可以使用实体布设组快速定位到所有属于该实体布设组的单位。

所有在场景内拥有物理实体的单位类型都可以将其归属于某个实体布设组，包括：*造物、角色、物件*

除此之外，*地形*也可以归属于某个实体布设组

同一个实体可以归属于多个实体布设组。

# 二、实体布设组的全局定义

在使用实体布设组之前，需要预先在实体布设组管理工具中对其进行全局定义

在系统菜单中点击【实体布设组管理】，打开实体布设组管理工具。

![](../../../images/9b31ceb359660baa.png)

左侧为实体布设组管理栏，可浏览已有的实体布设组，或点击【添加实体布设组】来增加一个新的实体布设组。

选中某个实体布设组后，可在右侧详情栏对其做一些设置，也可以看到该实体布设组的内容列表

![](../../../images/bb40a05940fa2234.png)

实体布设组管理栏可以新建页签，以及将实体布设组按页签分类

![](../../../images/17c4d45e16dd9cd8.png)![](../../../images/91c8a74bef3ee190.png)

# 三、管理实体布设组

## 1.将实体加入实体布设组

在地形编辑页签，右键点击地形可在弹出菜单中将其添加至实体布设组。

![](../../../images/b778f6b1179257e3.png)

在实体摆放页签，右键点击实体（多选可先通过按住shift+左键点击选中多个实体）可在弹出菜单中将其添加至实体布设组。

![](../../../images/23a7498ef9c0a98c.png)

在实体布设组详情界面点击右下角【场景中选中】进入选中模式，可通过左键框选或点击的方式快速添加实体至当前组。

![](../../../images/e8d5a4a15ea321da.png)

![](../../../images/63435b655d277971.png)

## 2.实体布设组详情界面设置

![](../../../images/1d3750c182b0013b.png)

*实体布设组名称*：可自定义，用于区分不同的实体布设组

*索引*：该实体布设组的唯一标识，用于在节点图内修改实体布设组数据时进行标识

*初始创建*：决定该布设组内实体是否随关卡一同创建

注意：当实体布设组或者实体本身有一个勾选了初始创建，该实体就会随关卡一同创建

举例：实体a和b都在实体布设组G中，且实体a勾选了初始创建，实体b未勾选初始创建

当实体布设组G勾选了初始创建，则a和b都会随关卡一同创建

当实体布设组G未勾选初始创建，则只有实体a会随关卡一同创建

![](../../../images/1a095e635b8c03fb.png)

*内容列表*：枚举了该实体布设组内包含的所有单位

可以右键选中其中某个单位将其移出该组或更换其所属组

![](../../../images/33cebf61ddd254a1.png)
