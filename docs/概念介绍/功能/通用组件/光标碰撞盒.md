# 一、光标碰撞盒组件的功能

光标碰撞盒可挂载于实体上，用于光标射线的碰撞检测

# 二、光标碰撞盒组件的编辑

## **1.添加组**件

![](../../../images/992ac6f0a5b4afa8.png)

(1)在实体/元件编辑界面中，打开组件编辑页签

(2)点击下方的“添加通用组件”，选择并点击“光标碰撞盒”，成功添加

(3)点击“详细编辑”，展开编辑页

## **2.光标碰撞盒组**件的编辑

![](../../../images/2f3620bc27280f80.png)

|  |  |
| --- | --- |
| 配置参数 | 说明 |
| *初始生效光标碰撞* | 下拉菜单提供光标碰撞盒枚举  通过修改后面的勾选框，可以修改生效情况，修改后生效状态会同步到寻路阻挡编辑页内  ![](../../../images/ea29cf6893402683.png)![](../../../images/affa615b3d8e675b.png) |
| *\*光标碰撞体列表* | 枚举实体配置的所有光标碰撞体 |

# **三、**光标碰撞盒**的编**辑

## 1. **添加**光标碰撞

![](../../../images/0f8c4e3c8ff8c635.png)

通过点击![](../../../images/83217464861375ec.png)，添加光标碰撞

添加的光标碰撞**初始生效**默认开启

序号:X，X为该光标碰撞的**序号**，作为节点输入项可以调整该光标碰撞是否激活

## 2. 相关参数说明

![](../../../images/827f15599138adf3.png)

光标碰撞可以调整是否初始生效

单个光标碰撞可以通过【添加光标碰撞】按钮添加多个区域

![](../../../images/1efce3c198e447eb.png)

触发区形状可选长方体、球体、胶囊体
