# 一、小地图标识组件的功能

*小地图标识组件*，支持实体通过图标/范围等可视化标识显示在**预制小地图界面控件**中

小地图标识组件需要挂载于实体，支持*玩家*、*物件*、*造物*使用

小地图标识可以通过默认配置激活/关闭，也可以通过*节点图*控制指定小地图标识的激活/关闭

# **二、**小地图标识组件**的编**辑

## **1.添加组**件

![](../../../images/67b64343a5e42e3d.png)

(1)在实体或元件编辑界面中，打开组件编辑页签

(2)点击下方的“添加组件”，选择并点击“小地图标识”，成功添加

(3)点击“详细编辑”，展开编辑页

## **2.**小地图标识**组**件的基础信息

![](../../../images/87990d6aa4e92c93.png)

|  |  |
| --- | --- |
| 配置参数 | 说明 |
| *初始生效* | 下拉菜单提供小地图标识枚举  通过修改后面的勾选框，可以修改生效情况，修改后生效状态会同步到小地图标识详细编辑页内  ![](../../../images/209e4a20d9021134.png)![](../../../images/c93940f1013dc641.png) |
| *\*小地图标识列表* | 枚举实体配置的所有小地图标识 |

## 3. **添加小地图标识**

点击详细编辑可进入小地图标识的编辑

![](../../../images/30e3be566f8f10f8.png)

通过点击![](../../../images/18a51704d4c709c7.png)，添加小地图标识。

添加的小地图标识**初始生效**默认开启。

*标记X*，X为**序号**，作为节点输入项可以调整小地图标识的初始生效参数。

## 4. 小地图标识的参数说明

### (1)显示设置

![](../../../images/893d1716af856ad1.png)

|  |  |  |
| --- | --- | --- |
| 配置参数 | 说明 | |
| *初始所有玩家可见* | 若开启，则小地图标识生效时，满足条件的所有玩家都可以在其小地图界面控件上看到该标识 | |
| *跟随物体可见性* | 若开启，则实体隐藏时，小地图标识一同隐藏 | |
| *显示优先级* | 在同一位置的小地图标识，造成堆叠后，优先级更高的会覆盖优先级低的。数字越大，优先级越高 | |

### (2)标记样式

![](../../../images/2465c86281b4c810.png)

|  |  |
| --- | --- |
| 配置参数 | 说明 |
| *选择类型* | 分为图标、范围、标记点、玩家标记、造物头像几种，不同类型会带有不同的配置参数 |
| *显示高低差* | 开启后，高低差超过10m的实体会在小地图内额外标记 |
