# 一、编辑模块切换

玩家与职业编辑：[玩家](/ys/ugc/tutorial//detail/mhctmgi51lpo)[角色](/ys/ugc/tutorial//detail/mh3ecor1x5cm)[职业](/ys/ugc/tutorial//detail/mhodlcrpht3q)单位状态编辑：[单位状态](/ys/ugc/tutorial//detail/mh6rh59iil2i)技能编辑：[技能](/ys/ugc/tutorial//detail/mho81frl33im)本地投射物编辑：[本地投射物](/ys/ugc/tutorial//detail/mhciimiw86jg)道具编辑：[道具](/ys/ugc/tutorial//detail/mhbgx0rspbqu)

# 二、新建与保存

![](../images/51928c28efda6d10.png)

通过资产栏的新建按钮可新建当前选中编辑模块对应内容。

![](../images/cfdef4dfe0215eae.png)

角色与职业编辑模块的内容修改后会自动保存，而单位状态、技能、本地投射物和道具的内容修改后需要手动进行保存。资产栏内对应内容出现黄色感叹号标识（如图所示）代表当前内容有未保存内容，可通过底部的保存按钮（如图所示）进行保存或另存为新内容。

# 三、切换性别

![](../images/7e51f3aaf9491491.png)

底部的切换性别按钮可切换模特模型的性别。

# 四、镜头回正

![](../images/0050164edf961bd6.png)

在战斗预设模块，右键场景空白处可呼出镜头回正选项，选择后镜头会恢复至初始状态
