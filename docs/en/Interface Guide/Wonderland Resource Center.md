# 1. Function Entry

![](../images/750bdd5fe0f955ae.png)

Open the editing interface system menu, press the button marked in the lower left corner of the image to access the Resource Center website.

# II. Main Interface Introduction

![](../images/d4e5c5c5a2f9a014.png)

## 1. Title Bar

The title bar includes the following functions:

Search box: Supports searching by asset name or creator information

![](../images/295e551532e4c626.png)

The button functions from left to right are:ProfileFavoritesSystem NotificationsUpload AssetsInstructions (including "Craftsperson Creation Code" and User Manual)

![](../images/f2768aaeaa134945.png)

## 2. Filter Bar

The filter bar includes the following functions:

Filter: Press the filter button to open the tag popup window, click options in the popup to filter assets. Press Reset to clear currently selected tags

![](../images/732e0e4542c17c50.png)

Feedback: Click the feedback button to open the feedback window. If the current tags cannot meet your filtering needs, you can provide feedback here. The available tags will be updated based on feedback received.

![](../images/098143eb1c85c6fd.png)

Time Published and Sort By

![](../images/4d85eed9aeff5a2c.png)![](../images/b6efca67825e35ca.png)

## 3. Asset Cards

![](../images/423e1036f6b3d2e2.png)

The asset card includes the following functions:

Click the button in the top-left corner![](../images/3b43feb4e3d721cf.png)to copy the asset details page link directlyThe buttons in the top right corner![](../images/1f7c5844514a7716.png)are: Download, FavoriteClick on the asset card to enter the asset details page

# 3. Details Page Introduction

![](../images/b880fab59fad04c7.png)

The details page includes the following features:

Download ResourcesLikeFavoriteCopy asset details page linkMore options: (Visitor) Report asset, (Creator) Remove asset, Edit asset

![](../images/45047da24aff070e.png)

# 4. Upload Asset Page Introduction

![](../images/20c5fe01117e44de.png)

The upload page includes the following functions: (For specific upload restrictions, please check the Resource Center)

Select assets: gia, gil files. For file acquisition methods, please refer to [Import/Export Assets](/ys/ugc/tutorial//detail/mhxbd59urbfu)Asset NameImage MaterialVideo MaterialCoverAsset IntroductionAsset Tags: If the current available tags do not meet your needs, you can provide feedback through the feedback button

# 5. Profile Introduction

![](../images/90d05688e5766782.png)

![](../images/a2878c8960ba93c6.png)
