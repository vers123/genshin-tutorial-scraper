# I. Miliastra Sandbox Entry Point

Automatically opens when entering Miliastra SandboxAfter closing, open Miliastra Sandbox from the bottom-left of the Start Menu

![](../images/f96204eb6254c4f2.png)

# II. Miliastra Sandbox UI Appearance

The left standalone window is the Resource ExplorerThe right standalone window is the Node Graph ExplorerWhen multiple tabs are present, you can drag to reorder them or pull one out to create a sub-window

![](../images/c89fae76c3843f92.png)

# III. Resource Explorer

Displays objects, prefabs, and other resources already present in the current session

![](../images/9bc927cd87500d85.png)

# IV. Server Node Graph Explorer

The Server Node Graph Explorer opens by default when Miliastra Sandbox is enabledThe upper section lists all currently created Server Node GraphsThe lower section lists resource objects that can mount Server Node GraphsMain functions of the Server Node Graph Explorer:Create and manage Entity Node Graphs, Status Node Graphs, Class Node Graphs, and Item Node GraphsYou can import Server Node Graphs from external Node Graph assets

![](../images/a76c9627e3cfc8f2.png)

Open the following via [Window] in the top Menu Bar:Resource ExplorerClient Node Graph Resource ExplorerNode ExplorerLogServer Signal ExplorerLoad Detection

![](../images/2592347695e756f7.png)

# V. Client Node Graph Resource Explorer

Main functions of the Client Node Graph Resource Explorer:Create and manage character skill node graphs, creation skill node graphs, creation status node graphs, creation status decision node graphs, and local filter node graphs.Local Filters include two types: Boolean filters and Integer filtersYou can import Client Node Graphs from external Node Graph assets

![](../images/ef628503494e0c3b.png)

# VI. Node Explorer

Main functions of the Node Explorer:View all current node categories and node detailsCreate and manage Composite NodesImport Composite Nodes from external node assets

![](../images/3d61857f2ec4301e.png)

# VII. Log

Main logging functions:Select specific node graphs to record runtime information in real time while the stage is running

![](../images/cb160d36d7c631a6.png)

# VIII. Server Signal Explorer

Main Functions of Server Signals:You can customize signal parameters and later use the corresponding signal node to implement signal transmission

![](../images/807f00fd0a269a3e.png)

# IX. Load Detection

Main functions of Load Detection:Detects and records node graph load data at runtime

![](../images/deeea42e8539b3e4.png)
