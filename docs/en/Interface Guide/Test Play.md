# I. Function Overview

The Test Play feature can be used for stage testing. Creators can configure Test Play Settings and Test Play Controls to meet their testing needs in different scenarios, enabling rapid validation of stages.

# II. Function Entry Point

System Menu - Test Play

![](../images/3298c46525824fa8.png)

# III. Function Restrictions

The Test Play feature cannot be used while a multiplayer Test Play room is active.

# IV. Test Play Verification

After clicking [Test Play], required verification and upload steps run. If a condition isn't met, an error code pops up for review. When all checks pass, the process continues and the [Test Play Settings] window opens.

![](../images/9306400ac51f57ce.png)

# V. Test Play Flow

The Test Play Flow consists of: Pre-Test Play preparation (upload, verification process) — Cosmetic Display — Loading Interface — Enter Stage — Stage Settlement

## 1. Pre-Test Play Preparation

### (1) Selection of Playtesters

![](../images/e875d5342c102d10.png)

*Test Play Player ID*: Click to load configured data from [Stage Settings], then choose which player ID to use for this playtest.

### (2) In-Game Save Data Settings

![](../images/1a33b812d9fc8a0d.png)![](../images/865f75a0fbbb077c.png)

You can configure In-Game Save Data settings according to your needs via System Menu — Manage Test Play Temporary Data

![](../images/32c5ed30b831e9d7.png)

In Test Play Settings, you can reference chip data in [Test Play Data].

## 2. Cosmetic Display

![](../images/cdb70522f0ec000c.png)

*Cosmetic Display Phase*: When disabled, Test Play skips the Cosmetic Display phase and goes directly to the Loading Interface.

## 3. Stage Settlement

![](../images/b0c153dae39ff9c6.png)

Players trigger Stage Settlement by completing the challenge or exiting manually

To speed up testing and reduce Test Play steps, turn off [Enable Test Play Settlement] in [Test Play Options] to skip settlement-related steps.

## 4. Test Play Manekin

![](../images/b85f29fed202e052.png)

Before starting a playtest, creators can use [Test Play Manekin] in [Test Play Options] to set which avatar body type is used.

## Language for Test Play

![](../images/50b4d4ac74a42d0f.png)

Before entering the demo, creators (Craftspeople) can select the language to use via a drop-down menu, eliminating the need to switch languages ​​in the settings.

## 6. Loading Interface

![](../images/ff1029fbcde5dd4f.png)

After completing the Cosmetic Display, Test Play shows the pre-entry Loading Interface according to [Stage Settings] -> [Loading Interface].

## 7. Enter Stage

![](../images/051ae852211e5efa.png)

After clicking the button, the stage entry flow runs per the creator's settings (Cosmetic Display -> Loading Interface -> Enter Stage).

# VI. In-Game Controls for Test Play

## 1. Exit Button

![](../images/42cf5cb691676f8a.png)

During playtest, open the [Test Play Controls] panel via the top-left Exit button or the Esc hotkey.

![](../images/bc8f1631526f18d4.png)

## 2. Test Play Controls

![](../images/294f7fc2b04976ed.png)

### (1) Continue Challenge

Clicking the [Continue Challenge] button will return you to the current playtest session.  
![](../images/402acb073b31c81a.png)

### (2) Retry Challenge

When the [Retry Challenge] button is clicked, all startup processes from the stage entry sequence are executed again. Once the processes finish, a new playtest run starts.

Note: If an error prevents an immediate restart, exit playtest and start the playtest flow again.

![](../images/432291b819721a9b.png)

### (3) Abandon Challenge

Click to end the current playtest immediately and trigger the corresponding non-standard settlement result.

![](../images/7faf166083099b47.png)
