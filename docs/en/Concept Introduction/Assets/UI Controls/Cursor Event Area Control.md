# I. Cursor Event Area Control Functions

![](../../../images/e2861c9e96d0f9c0.png)

The *Cursor Event Area Control* is an area that can receive cursor raycast events. For example, it can be combined with Image and Text Box Controls to create a basic Button

The Cursor Event Area Control is a Client Control that can have *Client Scripts* attached and can be called through *Client Scripts*

API Reference: Search for `CursorEventArea` in the API documentation to view the related Script APIs

# II. Cursor Event Area Control Configuration

![](../../../images/848e55c2ba9987a0.png)

## 1. Click Response Area

*Persistent Area Preview:* Keeps the color block indicating the Cursor Event Area visible while editing other controls*Raycast Target:* Detects cursor hover and click input within the control area

## 2. Controller Navigation

*Selectable via Controller Joystick Navigation:* Determines whether this control can be selected via controller navigation

When enabled, you can configure which other controls are selected when navigating in each of the four directions with the controller
