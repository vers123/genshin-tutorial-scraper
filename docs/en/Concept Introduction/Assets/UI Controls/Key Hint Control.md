# I. Key Hint Functions

![](../../../images/c5f16a5e14a03f66.png)

The *Key Hint* is a preconfigured hint control that supports displaying shortcut key prompts for PC, keyboard and mouse, and controller input

The Key Hint Control is a Client Control that can have *Client Scripts* attached and can be called through *Client Scripts*

API Reference: Search for `UIKeyHintControl` in the API documentation to view the related Script APIs

# **II. Key Hint Configuration**

![](../../../images/baff5782d042ee68.png)

## 1. Key Hint Settings

Configures the display of shortcut key prompts for PC, keyboard and mouse, and controller input

## 2. Controller Navigation

*Selectable via Controller Joystick Navigation:* Determines whether this control can be selected via controller navigation

When enabled, you can configure which other controls are selected when navigating in each of the four directions with the controller
