# III. Progress Bar Feature Upgrade

Progress Bar customization is now available. Now, Craftspeople can create custom backgrounds and textures for their progress bars, with textures based on dynamic masking tied to the bar's current value. (Note: Animated assets in the texture cannot be cropped according to progress.) Craftspeople can choose between horizontal, vertical, or radial fill modes to achieve different visual effects
