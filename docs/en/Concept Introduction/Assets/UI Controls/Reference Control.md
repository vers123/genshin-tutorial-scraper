# I. Reference Control Functions

![](../../../images/4f39b9849d2988f4.png)

The*Reference Control* can reference other Client Control Templates and supports previewing them

The Reference Control is a Client Control that can have *Client Scripts* attached and can be called through *Client Scripts*

API Reference: Search for `ReferenceControl` in the API documentation to view the related Script APIs

# II. Reference Control Configuration

![](../../../images/111b9a08f29fe8ce.png)

## 1. Template Reference

*Reference Control Template:* References controls saved as Client Control Templates. At runtime, the Reference Control has the same functionality and appearance as the referenced template

## 2. Controller Navigation

*Selectable via Controller Joystick Navigation:* Determines whether this control can be selected via controller navigation

When enabled, you can configure which other controls are selected when navigating in each of the four directions with the controller
