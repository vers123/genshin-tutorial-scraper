# I. Pop-Up Functions

![](../../../images/fe319fc9b126cb76.png)

An interface that appears while running a stage due to logic triggers. It is used to provide information, hints, options, or interactions for players.

# **II. Editing Pop-Up Window**

![](../../../images/79e9a9c95e91c696.png)

*Title*

Text shown in the title area (see the graph)

*Text Content*

Text in this area (see the graph) is the same as the content in the text box, supporting the insertion of *custom variables* for players and stages

During stage runtime, the displayed text updates in real time as custom variables change
