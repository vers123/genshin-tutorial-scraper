# I. Functions of the Text/Image Input Box

*Text/Image Input Box* can be configured in the interface layout, suitable for scenarios where images and text are used in a mixed arrangement

In the Text/Image Input Box, images are dynamically adapted based on the actual length of the text content

# **II. Editing the Text/Image Input Box**

![](../../../images/198cf1e08da2619d.png)

## **1. Add Text/Image Input Box**

In the *UI Control Group Editor Window*, add the UI control template - Text/Image Input Box

![](../../../images/2ebbdf6b14ca9dab.png)

## 2. Text Box Settings

![](../../../images/1e7e5f3c978e02dc.png)

*Font Size*: The font size of the text in the Text/Image Input Box

*Line Spacing*: The line spacing in the Text/Image Input Box, measured in units of the font size. (Actual Line Spacing = Current Font Size × Line Spacing Value)

## 3. Image Settings

![](../../../images/fe65e52ea3ac2db5.png)

In the Text/Image Input Box, click "Insert Image" to add an image

Image color cannot be modified. When the image source is set to "Static Reference," Asset Groups cannot be used

*Position*: The location of the Text/Image Input Box, measured in units of the current font size. (Actual Offset = Current Font Size × Offset Value)
