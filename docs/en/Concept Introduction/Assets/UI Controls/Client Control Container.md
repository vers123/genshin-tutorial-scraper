# I. Client Control Container Functions

![](../../../images/682ca71d823dfd80.png)

*Client Control Containers* allow *Client Controls* to display properly while a Wonderland stage is running

If the Interface Layout does not contain a Client Control Container, Client Controls will not function or display properly, and Client Scripts attached to them will not run properly

# II. Editing Client Control Containers

## 1. Add a Client Control Container

In the *UI Control Group Editor*, add UI Control Template > Client Control Container

![](../../../images/a5c5c297613ce522.png)

## 2. Interface Configuration - Canvas Settings

Select the Client Control Container added above, then go to Canvas Settings > Go to Edit to open its Details page and edit the Client Controls it contains

![](../../../images/a8a627c4cc29f825.png)

## 3. Interface Configuration - Client Control Container/Details

On the Client Control Container Details page opened above, click Add Control to add the required Client Controls

![](../../../images/259f1841e5d94221.png)
