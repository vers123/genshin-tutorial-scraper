# I. Scoreboard Functions

![](../../../images/3ba1b20aaf98bf49.png)

Displays the player's custom variables during stage runtime and ranks them accordingly

# **II. Editing the Scoreboard**

![](../../../images/b78afcc7dd4cdd1b.png)

|  |  |
| --- | --- |
| Configuration Parameters | Description |
| *Sort* | Provide ascending and descending order for values |
| *Type* | The selection of self, faction, or type will affect the configuration content of the remaining parameters |
