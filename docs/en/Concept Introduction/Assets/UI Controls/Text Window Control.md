# I. Text Window Functions

![](../../../images/ad4ec7a4c360ab4b.png)

The Text Window provides the same basic functions as the Text Box. For details, see [Text Box UI Control](/ys/ugc/tutorial//detail/mhnltrr3g966)

In addition to the functions of the Text Box, the Text Window also supports scrolling

The Text Window Control is a Client Control that can have *Client Scripts* attached and can be called through *Client Scripts*

API Reference: Search for `TextWindowControl` in the API documentation to view the related Script APIs

# **II. Text Window Configuration**

![](../../../images/3c2df53cbda2f2cd.png)

## 1. Text Box Settings

*Can Scroll:* When enabled, the Text Box can be scrolled*Show Scrollbar:* Editable only when Can Scroll is enabled. When enabled, a scrollbar is displayed for the Text Box

![](../../../images/8a4be196c28fedbf.png)

## 2. Controller Navigation

*Selectable via Controller Joystick Navigation:* Determines whether this control can be selected via controller navigation

When enabled, you can configure which other controls are selected when navigating in each of the four directions with the controller

![](../../../images/d36153617f52167f.png)
