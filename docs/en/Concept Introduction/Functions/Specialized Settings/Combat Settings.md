# I. What are Combat Settings

Provides more detailed configuration for custom combat gameplay, enabling players to configure attack and hit response settings

# II. Editing Combat Settings

In the Specialized Settings tab, click *Advanced Editing* to enter the entity's combat settings

![](../../../images/7c45b938ccfd1080.png)

|  |  |
| --- | --- |
| Configuration Parameters | Description |
| *Cannot Be Affected by Elemental Effects* | Configure whether this object can be affected by elemental effects |
| *Cannot Be Targeted* | Configures whether any function that targets and locks this object will take effect |
| *Cannot be targeted by allied units* | When enabled, this entity cannot be selected as a target by the following features: Creation Autonomous LogicHitbox AttackRay Detection Note: Even when this option is enabled, the entity can still be selected as a target for skill attacks |
| *Cannot be targeted by enemy units* | Same as above |
| *Bullet Tracking Point* | The name of the attachment point that bullets will track |
| *Hit Effect* | Configures special effect to play when the object is attacked |
| *Knockdown Effect* | Configures special effect to play when the object is destroyed or downed |

The hit effects and knockdown effects can be further configured on the Edit Details tab

![](../../../images/038ec84d5e6d649a.png)

|  |  |
| --- | --- |
| Effect Configuration Parameters | Description |
| *VFX Asset Type* | *Only* *Timed Effects* *can be selected*  For effect-related assets, see [Special Effects](/ys/ugc/tutorial//detail/mhe1030vx380) |
| *Special Effects Assets* | You can select Special Effects Assets. After selecting a Special Effects asset, you can preview it in the scene![](../../../images/73d1cdafed427aa2.png) |
| *Zoom Factor* | Zoom factor of the effect |
| *Offset* | Specified Relative Position |
| *Rotation* | Specifies the rotation information of the special effect |
