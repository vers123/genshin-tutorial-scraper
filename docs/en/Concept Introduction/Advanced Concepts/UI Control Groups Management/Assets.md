# I. Definition of Assets

Craftspeople can create multiple custom asset groups in *Assets*

An Asset Group is data saved after combining and editing parameters for one or more UI control templates

For UI controls that support Asset Group configuration, you can reference predefined Asset Groups to enhance the control's visual presentation

# II. Editing Assets

## 1. Create Asset Group

Select Assets and click "Add Asset Template" to add the currently supported UI control templates to the Asset Details

![](../../../images/e94d3304699a44ec.png)

After adding, you can select any UI control to combine, and click "Create Asset Group" to generate an asset group![](../../../images/bd00c28a9a3c26de.png)

After creating an Asset Group, you can choose whether to enable the mask. Enabling the mask lets you configure it for the Asset Group

Note: Masks do not support mask effects

![](../../../images/56705cf747691c16.png)

## 2. Referencing Asset Groups

For example, in the Status Display Area control, asset groups can be referenced in the "Reference Asset" field

![](../../../images/c7adc095ae3cd7fe.png)

Click "Edit Details" to create a new Asset Group or directly reference an existing Asset Group

![](../../../images/4785f1c3a0ab63e8.png)

## 3. Preview Settings When Editing Asset Groups

After entering the Asset Group editing interface, the currently edited Asset Group will be isolated from the canvas where the mask and controls are located. The Asset Group's position on the canvas is for preview purposes during editing only and will not affect its relative position based on its associated control

In Settings, you can configure the visibility of the mask and the source control of the asset group during editing preview

![](../../../images/3ba5d3c4b56508c5.png)
