# I. Location of Entry

![](../../../images/da65b293f0faa462.png)

Click the System Menu button (top-left) to open the menu interface

![](../../../images/9502239ff76a5d34.png)

Click [Manage Wonderland Gift Box] to open the Wonderland Gift Box editing interface, used to create additional in-game content for distribution to players

# II. Feature Details

## 1. Create Gift Box

Click Create Gift Box to create a new Gift Box

![](../../../images/776471cbf7e4ac74.png)![](../../../images/1af1efad7f2b5b49.png)

Each Stage can contain up to 20 Gift Boxes

## 2. Base Attributes

![](../../../images/a0dfcf3938cd6d7d.png)

*Gift Box Index*: The unique identifier of a Gift Box; must be unique. When Creators (Craftspeople) upload a save, the Gift Box IDs in the current save must be a subset of the online version's Gift Box IDs for a successful upload

*Select Icon*: Select an icon for this Gift Box from the provided icons, or upload a custom icon from your local device

*Rarity*: Indicates the quality of this Gift Box

*Unlock Condition Type*: Specifies how this Gift Box can be obtained: through Leaderboard, Ranks, or Ultimate Achievement

![](../../../images/5a94db208fc6ff20.png)

When selecting a Leaderboard, first choose which leaderboard data to use as the condition, then set the required rank to achieve

![](../../../images/44bc62c2d71f4c8b.png)

![](../../../images/6fcb779d1750d163.png)

When selecting a Rank, choose the ranking requirement to achieve

![](../../../images/e5cbf454b03e9ef2.png)

When selecting Ultimate Achievement, no additional editing is required

![](../../../images/a7aa01f66efbea1c.png)

*Can it be obtained again after the season update?*: When enabled, players can obtain this Gift Box again when the Season updates

*Validity Period*: When disabled, the Gift Box remains permanently active. When enabled, allows setting the number of Seasons it stays active for the player

*Number of valid seasons after obtaining*: Specifies the number of Seasons this Gift Box remains active for the player after being obtained

*Description Content*: Describes this Gift Box's function

## 3. Apply Settings

Defines the Seasons during which this Gift Box can be active

![](../../../images/b6d817df11bf652a.png)

*Activate?*: When disabled, this Gift Box will not be available under any circumstances. When enabled, it becomes available during the configured Season

*Display Priority*: The display order of this Gift Box in the Shop area; higher values appear first

*Permanent Effect After Activation?*: When disabled, set the effective Season via Listing Settings by choosing the corresponding Season; when enabled, specify the initial effective Season, after which the Gift Box remains listed permanently

![](../../../images/27f92b69ec78ac4f.png)

## 4. Launch Settings

Defines which Gift Boxes are listed for each Season

![](../../../images/e5d6b8d9400225d4.png)

*Select Season*: Select a Season to edit the Gift Boxes to be listed for that Season

*Add*: Add Gift Boxes to be listed in the currently selected Season

![](../../../images/a56b86ee66775564.png)

Click the top-left corner or uncheck to remove the Gift Box from the Season. Permanent Gift Boxes cannot be removed in Listing Settings
