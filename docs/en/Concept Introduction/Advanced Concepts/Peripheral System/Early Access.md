# I. Definition of Early Access

The *Early Access* function lets creators (Craftspeople) quickly publish stage gameplay prototypes for online testing, while informing players that the stage is still being refined. It can also be used to collect immediate feedback from players.

After an *Early Access* version is released, the stage's play data and positive/negative reviews will accumulate under the normal rules. The Craftsperson can continue updating the stage until the official version is released.

# II. Release Early Access Stage

## 1. Getting Started

On the **first release** of a Stage, while editing the preview info, you can choose to release it as an "Early Access" version. (Otherwise, it will be released as the official version directly.)

![](../../../images/1f6d65fe680fea51.png)

The Craftsperson can fill out the description text under "*Early Access Version Description*" below

## 2. Early Access Version Rules

When a Craftsperson's stage is in the *Early Access* state, released updates will display as "X.xx Early Access Version". After the official version is released, the official version update counter will start from 1.01.

## 3. Release the Official Version of a Stage

After releasing an *Early Access* version, you can switch the stage to *Official Version* from the same location the next time you release it

Note that once you confirm releasing of the *Official Version*, the stage can no longer be changed back to an *Early Access* version
