# I. What Are White-Box Objects?

White-Box Objects are a set of basic geometric shapes used to validate stage design.

White-Box Objects provide standard shapes and material display modes for spatial validation and design prototyping during editing. They can be used as normal model assets and support scaling, color changes, material changes, Logic Component mounting, Node Graph mounting, and other functions.

# II. White-Box Object Editing Entry Point

![](../../../images/41d39e8ba98e5eb3.png)

White-Box Objects can be found under Entity Editing Tab → Prefab → Dynamic Units → Other. Drag the corresponding Object into the Scene to use it.

# III. White-Box Object Types

The following standard White-Box geometry is supported:

Cuboid

Sphere

Plane

Triangular Prism

Pentagonal Prism

Triangular Pyramid

Pentagonal Pyramid

Cylinder

Cone

Wireframe Cuboid (commonly used for area marking)

Wireframe Cylinder (commonly used for area marking)

# IV. Additional Notes on White-Box Objects

![](../../../images/dc1e723f8ae0f2ba.png)

Grid Lines: Each grid is a standard 1 meter long

![](../../../images/f063029e8d25566a.png)

Wireframe Cuboids and Wireframe Cylinders cannot have their materials changed.
