# 一、风险检查功能是什么

*风险检查功能*可以对当前奇匠正在编辑的奇域进行检测，当奇域配置中使用了不建议的配置方法或违背了某些隐藏规则时，会主动发出提示与说明

风险检查功能与*试玩校验*的区别如下：试玩校验中的错误会阻止试玩的正常进行，属于比较严重的阻碍性错误，会导致功能无法正常运行；而风险检查中的提示则不会阻止试玩，不会影响功能的正常运行，一般是数据上的错误

# 二、风险检查功能的使用

## 1.入口

在系统菜单中点击【风险检查】，打开风险检查界面。

![](../images/4e12ec3381968311.png)

## 2.界面介绍

![](../images/0b611a199fa6885d.png)

点击【发起检查】即可对当前的奇域进行检查

![](../images/0d121c04d793353a.png)

左边时间表明该次检查发起的时间

检查记录的存在上限为5条，如果超过5条，则新的记录会替换掉最早的检查记录。检查记录仅在当次编辑时保存，重新加载存档则会清理掉之前的记录

右边则全量显示当前奇域所检查出的风险项

# 三、特别说明

【存在跨逻辑子图的运算流连线】指的是下图红框中的情况，即将下方逻辑子图中的运算流数据连入了上方逻辑子图中的运算流，会导致数据传递出现错误
