最终值=（基础值+变更量）\*（1+调整率）\* 倍率 + 修正值

“变更量“表示基础数值的变化程度  
“调整率“表示数值额外缩放的系数  
“倍率”表示数值整体缩放的系数  
“修正值”表示数值最终增减的变化程度

说明：其中某些单位状态有动态的版本，用节点动态修改单位状态的方法可以参考[单位状态](/ys/ugc/tutorial//detail/mh6rh59iil2i)中
